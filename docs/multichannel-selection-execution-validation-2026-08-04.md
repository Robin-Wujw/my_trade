# 多通道选股与买卖匹配验证

## 1. 研究结论

本轮研究解决的不是单独提高选股分数或放宽买点，而是让候选来源、入场结构、持有周期和风险预算互相匹配。最终冻结方案在 2021 至 2023 年训练期通过验收，并在不回调参数的前提下完成 2024 年唯一一次揭盲验证。

结论如下：

- 紧结构平台延续通道关闭。它在共享资金下持续负贡献，不再为了保留三通道形式占用仓位。
- 因子周期候选只交易深回撤反转，不再把泛化前十名直接交给固定周期持有。
- 低广度反转继续保留，用于 Formula33 广度低位后的连阳一半拉回。
- 左侧价值网格保留，但不放大。训练期和验证期的主要利润都来自右侧匹配通道。
- 2024 验证结果没有用于二次调参；2025 至 2026 数据仍未参与本轮选择。

该方案是已验证研究候选，不自动替换现行生产策略，也不连接 MiniQMT 下单接口。

## 2. 四步走

### 第一步：诊断选股与买卖错配

原问题不是简单的候选质量不足，而是同一组候选被不同买卖逻辑混用：

- 紧结构候选需要短周期平台延续，但共享资金回测中持续负贡献。
- 因子前十名具有明显的周期差异，泛化固定持有不能稳定盈利。
- 低广度反转需要市场广度条件与价格拉回同时成立，不能等同普通趋势买点。
- 左侧价值网格交易次数较多，但净贡献有限，放大它不能解决总体收益问题。

### 第二步：按通道匹配执行方式

最终保留两条主要右侧通道：

1. 因子周期匹配：候选进入已冻结的因子前十名与结构接近区间后，还必须满足 60 日收益不高于 -10%、MA20 尚未上扬，并排除 Formula33 观察阶段；次日开盘执行，固定持有 20 个交易日。
2. 低广度反转：Formula33 最近 21 日正式去重数严格低于 50，再等待连阳一半拉回与次日收盘确认；使用结构止损、3R 目标和 20 日时间上限。

左侧价值线继续按 2% 单格、5% 网格间距和单股 10% 成本暴露管理。紧结构通道不启用。

### 第三步：只在训练期冻结参数

训练区间为 2021-01-01 至 2023-12-29。最终参数：

| 项目 | 冻结值 |
|---|---:|
| 总持股上限 | 5 只 |
| 左侧标的上限 | 2 只 |
| 组合总暴露上限 | 100% |
| 因子周期风险预算 | 2.4% |
| 因子周期固定止损 | 8% |
| 因子周期单股上限 | 30% |
| 因子周期同时持有上限 | 5 只 |
| 因子周期持有期 | 20 个交易日 |
| 因子周期 60 日收益上限 | -10% |
| 低广度反转风险预算 | 1.8% |
| 低广度反转单股上限 | 30% |
| 低广度反转同时持有上限 | 2 只 |
| 紧结构通道 | 关闭 |

成交成本固定为佣金 0.0085%、最低 5 元、卖出印花税 0.05%、滑点 0.05%。A 股整手、T+1、停牌、涨跌停和不可成交状态继续由统一组合引擎处理。

### 第四步：2024 唯一揭盲

2024 候选合并后共有 242 个交易日快照，财务和行业清单均通过时点标记检查。揭盲使用与训练期完全一致的参数，没有根据结果修改过滤条件、仓位或持有期。

正式买卖报告和中文买卖流水统一显示中文信号类型、阻断原因、买卖理由和候选失败原因。内部 `signal_type`、`reason`、`entry_evidence` 等英文代码继续保留，用于程序判断和审计；展示层使用对应的 `*_cn` 字段或中文转换函数。

训练期与 2024 验证期的正式报告已检查，英文蛇形信号码和 `L/R` 批次码展示命中数均为 0。未知的新英文信号码不会直接漏到中文报告，而会显示中文的未识别提示，要求后续补充映射。

- 正式买卖报告已移除“期末持仓相关未成交信号”内部字段表，不再显示股票、日期、信号、旧证据分、交易分、领导力和未成交原因；这些内部字段仍保留在 summary JSON 中供审计。
- 买卖报告中的股票简称和缺失行业标签是回测结束后用当前 `stock_basic` 快照回填，仅用于展示，不参与历史选股、行业限额或ST判断；无法映射的行业显示“未映射”。

## 5. 边界

- 本轮使用已经冻结的本地候选、Formula33 历史和准备行情，并显式使用 `--no-refresh-inputs --allow-frozen-inputs`。候选清单的财务与行业时点标记为真，但该运行仍属于研究验证，不替代生产前的数据刷新与完整性门禁。
- 技术信号使用截至观察日的前复权序列，成交和估值使用原始未复权价格；逐笔成交审计核对原始日 K 区间和候选时点。
- 日 K 的 `close_proxy` 只是 14:55/收盘确认近似，不能证明真实盘中排队和冲击成本。
- 2024 已经揭盲，后续不得再用 2024 调整本方案。下一步若继续研究，应把参数保持冻结，并使用从未参与选择的新时间段或模拟盘前向观察。
- 2025 至 2026-07-21 也已经用于前向评价，不得再把这一区间用于参数选择。该段暴露出的右侧失效只能用于否决或提出新的研究假设；新的右侧模型必须重新划分训练、验证和未见样本，不能在本段反复调到盈利。
- MiniQMT 保持只读，不允许把研究信号直接连接券商下单接口。
