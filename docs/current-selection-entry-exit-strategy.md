# 当前选股与买卖策略

参数和审计收益以[当前冻结基线](current-baseline.md)及其[配置文件](../config/strategy_baseline.json)为准。本文描述当前代码行为；[旧 factor_quant 说明](selection-entry-exit-strategy-legacy-2026-07.md)已归档。

## 候选来源

右侧使用 `playbook_low_corr_network_cap1_price_only_residual_volatility_liquidity_30m`，六因子先在观察日可交易全市场截面计算分位并等权合成，部分因子缺失时按可用权重归一；随后要求可见ADV20至少3000万元，再保留Top50。完整定义见[模型与因子](current-models-and-factors.md)。数据仅截至观察日，排除未来上市、退市后、无有效成交、风险警示及历史不足的股票；缺复权因子不能以1替代。

左侧使用 `value_model`，要求行业白名单、公告日可见财务、有效价值线和安全门槛。右侧不继承旧基本面模型的市值、质量和增长门槛。两路分数不相加，同股合并权限后进入统一引擎；旧 `factor_quant` 仅供历史诊断。

日报的基本价值线、一般基本面栏目属于观察列表，其较宽门槛不能视为引擎买入许可。当前引擎新开价值左仓还要求：

| 字段 | 实际开仓门槛 |
|---|---|
| 现价 / 价值线 | 0.88 至 1.03 |
| 质量分 | 至少80 |
| 扣非同比增长 | 至少20% |
| 观察日总市值 | 至少150亿元 |
| 其他 | 左侧权限、白名单、交易资格有效，无价值证伪 |

这些历史门槛和白名单经过事后选择，不能视为已证实的价值优势。财务缓存没有完整revision vintage；行业区间存在也不保证历史分类版本完整。历史及新诊断均保留 `research_only`，缺时点证据不得放行严格PIT声明。

## 交易与记账

候选只决定观察范围，合格技术结构、风险距离、盈亏比、流动性及组合限制共同决定交易。收盘确认的信号在下一交易日开盘检查成交，绝不使用信号日收盘回填交易。盘中预埋限价按既有OHLC边界处理；日线不能模拟真实排队顺序。

执行保留A股T+1、整手及科创板最小申报数量、停牌、精确涨跌停、交易费用、滑点和公司行动记账。精确限价缺失时的板块估算必须披露，不能混称精确成交。公司行动缺派息日等限制继续进入结果资格。

主动仓和全部持股各最多5只，左侧最多2只，同业或高相关主题最多2只。两只左仓在场时最多再容纳3只普通右仓。左转右为不可逆管理切换：释放左侧名额，继续占总持股名额。利润尾仓可不占主动仓名额，但仍计入全部持股上限、市值与风险。

左侧网格不因每日榜单落选机械退出；明确价值证伪和组合限额按下一交易日规则处理。普通右侧继续采用结构止损、分批止盈和趋势尾仓管理。默认止损是收盘确认后次日开盘执行，跳空或封板可能使损失超过计划1R，不能称为硬止损。

当前冻结引擎仍按初始资金及成本暴露定仓、闲置现金收益为0。净值定仓、尾部风险预算、现金收益和盘中止损列入[预注册研究](research-registry.md)，验收前不替换冻结规则。

## 输出与前向边界

回测记录候选/Formula33输入哈希、实际执行参数、配置版本及偏差。配置参数一致不代表候选模型或输入一致，复现还须核对输入指纹。

前向验收要求当日真实捕获的候选、Formula33状态、纸面订单和完整数据收据。补抓历史记录不能补写过去的前向成绩。当前运行阻断及逐项验收见[计划执行记录](plan/quant-review-issues-2026-10-14.md)。

MiniQMT只读。订单只进入研究、提醒或纸面记录，不调用券商下单API。
