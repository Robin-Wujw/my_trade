# 现有数据是否足够执行计划

本次结论来自本机 SQLite 的只读覆盖核对，以及现有冻结输入包。现有数据足以继续工程优化和截至 **2026-07-21** 的固定历史诊断；无需先追赶之后的行情。它不足以把完整计划的真实前向样本、财报修订和行业历史时点缺口宣布完成。

| 目标 | 不继续拉新数据能否做 | 边界 |
|---|---|---|
| 引擎拆分、性能、配置、日报接入、离线回归 | 可以 | 工具验收不等于当日生产运行成功 |
| 2021—2026-07-21 固定候选、参数邻域、简单因子、止损和仓位对照 | 可以做研究诊断 | 共用冻结输入、成本和独立账本；保留 `research_only / data_limited` |
| 基准风险指标 | 2022起可以 | 本库2021指数缺失，不外推或拼成完整基准 |
| 新规则有效性、252日前向及每类100个不重叠campaign | 现有数据不能完成 | 登记后真实同日捕获并积累，不把历史补抓算成前向 |
| 严格无未来函数的完整财务/行业证据 | 现有数据不能证明 | 必须有真实公告修订版本、行业快照与来源时点 |
| 现金工具收益 | 尚无可验收来源 | 不默认填固定利率或事后挑最高收益；冻结基线现金收益继续为0 |

核对记录：`daily_kline`、`adj_factor`、`daily_basic`、`stk_limit`、`stock_st`、`suspend_d`、`index_daily` 的最大交易日均为2026-07-21；`index_daily` 最早为2022-01-04。`raw.tushare_dataset_row_versions` 有19,076行，最后捕获为2026-08-11 14:34:41，不能代表每天持续前向采集。

历史缺口还包括2019-05-09复权因子、部分精确涨跌停价、公司行动派息日、退市财务和完整历史财务/行业版本。现有缓存和原失败证据均保留；缺数据不当作停牌、无交易、零收益或无财报。

因此，执行顺序是先完成现有数据能支持的优化与固定实验，逐项保存结果和验账收据；依赖真实新捕获或真实缺失字段的目标继续明确列为未完成。用户此前指定的截至7月21日历史闭环已经验收，当前扩大后的完整计划仍按[执行台账](plan/full-plan-execution-2026-10-14.md)逐项推进。
