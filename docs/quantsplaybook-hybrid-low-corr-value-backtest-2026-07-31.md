# QuantsPlaybook 右侧与基本价值线左侧双通道回测

## 1. 组合结构

本轮将选股拆成两个互不加分的通道：

```text
右侧：playbook_low_corr 每日 Top50 -> 现有右侧结构买卖
左侧：严格时点基本价值线候选       -> 现有价值网格
                              -> 统一组合仓位与退出引擎
```

- 右侧来源标记为 `quantsplaybook_factor`，不再套用旧基本面候选门槛。
- 左侧只保留 `value_model`、行业白名单、财务和行业严格时点均合格的可执行行。
- 同股重合时合并为 `value_model+quantsplaybook_factor`，保留独立左右权限。
- 总持股最多5只，左侧最多1只，同一行业或高相关主题最多2只。
- 左仓触发合格右侧结构后不可逆地转为右侧管理并释放左侧名额；此后不得恢复左仓。
- MiniQMT 仍为只读数据源，不连接实盘下单。

生成入口：

```powershell
python -m apps.quantsplaybook_hybrid
```

产物：

```text
var/backtests/quantsplaybook_hybrid_low_corr_value_2021_to_20260721
```

## 7. 研究边界

候选、财务、行业、行情和交易执行满足严格时点规则，没有发现未来函数。右侧
`low_corr` 的权重只用2021-2023训练，2024选择，2025以后未参与调权。

但“双通道组合”是在已经查看过原价值线和 low_corr 历史结果后提出的，因此本次
组合级 2025-2026 不能称为完全未观察的模型选择样本外，只能称为严格时点集成回测。
此外，日K收盘确认仍使用14:55/收盘价代理，真实成交质量需要分钟数据验证。
