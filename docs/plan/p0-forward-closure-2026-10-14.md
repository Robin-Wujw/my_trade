## 实现与边界

默认 `apps.daily_pipeline` 现在是八步：`formula33 → sector_stats → sector_watch → factor_selection → fundamental_update → fundamental_selection → frozen_forward → daily_report`。第七步使用研究库的冻结六因子 Top50 与独立 `value_model` 左侧来源；旧的 cache-only 因子观察文件不会替代冻结候选。Formula33 失败则跳过前向步骤；冻结捕获失败则跳过正式日报。其它上游失败仍阻断日报。

`stock_research/pipelines/daily_forward.py` 串联以下工作：

1. 只允许实际当地日期 16:30 之后捕获，不接受补填日期；独占运行锁防止并发覆盖。
2. 调用已有增量同步，必须完整补齐数据、财报和当日回执，不能以旧交易日成功代替今日成功。
3. 调用 `forward_left.py` 独立生成左侧来源，保存财报和行业原始文件、SHA-256、实际捕获时间、评估股票数和候选数。当天重跑只复用哈希验证后的不可变快照。
4. 归档本轮 Formula33 原始文件、阶段及实际整数上行/下行 streak、窗口股票数，调用既有冻结捕获和纸面引擎，落盘候选、条件意图、回放和 manifest；后续阶段延续已发布前向记录。禁止用阶段反推 streak，缺字段或非非负整数时失败；独立捕获入口使用相同约束。代码、依赖和基线改变必须另建明确的研究流。
5. 检查完整产物后才允许本轮日报读取该 manifest。同日重跑会同时验证归档 Formula33、源文件、候选、意图及回放的哈希。

左侧不从日报观察池补造 PIT 字段：财报必须有当日同步回执，原始公告和最终公告均不得晚于观察日；行业使用当天真实请求的申万成员快照，沿用三级、二级、一级优先顺序及现有白名单。已知 ST、未上市、已退市、不在白名单及市值不足先排除；未知数据不能充当经济性淘汰。剩余模型范围内缺财报字段、缺行业或行业冲突均失败，只有完成这些评估后确实无入选股票才允许空左侧快照。统一候选门槛及引擎更严格的新仓门槛沿用现有实现；当前原始价格比较价值线，技术历史以观察日为锚重算前复权。行业和财报“当日可见”标志只证明今天的可见来源，不声明历史修订已经齐全，整个流仍是 `research_only / strict_point_in_time=false`。

年度来源复核后，`forward-value-left-v2` 独立读取真实可见年报 `fina_indicator.dt_eps`，禁止用半年 EPS、普通 EPS 或年化推算替代。年报扣非利润/年末总股本必须与该 EPS 相符，最新报告期归母净资产/期末总股本必须与 BPS 相符（每股数值允许 0.005 元报告舍入误差）。不相符意味着加权股本或修订基准尚未确定，明确失败，不猜测调整。逐股当日完整 `dividend` 响应只取已公告并实际实施的除权事件，年末至最新报告期、最新报告期至观察日分别复合送转比例；股数链还须与当日 `daily_basic.total_share` 一致。现金分红不调整股数，发行/回购等不能被现有来源解释的变化标为不足。每次成功的逐股响应有捕获时间与哈希，网络失败不视作零分配，已取得的有效来源保留以便重试。

候选保留原始及观察日可比 BPS/年度 EPS、真实年度报告期及公告日、复合调整因子、股数基准与四份来源 SHA（年度、送转、当前财务、行业）。增长保留最新报告期扣非净利润同比及其近似来源标识。质量分继续使用已有 Tushare EPS/增长/ROE 代理，并显式标识；它与 MiniQMT 的三年盈利成长质量分不等价，不能据此宣称完整模型完全同口径。既有历史 Tushare 缓存计算不改，当前报告期 EPS 的历史限制也没有被本次前向工程消除。

R07 的固定增长封顶只写独立旁表 `r07_growth_cap_diagnostics.json`。它读取统一白名单与真实年度来源下、质量/增长/价格价值比过滤前的 `value_observations.json`，避免只比较原公式最后入选股票；生产候选不变。两个文件均绑定左侧 manifest 的 SHA 与实际采集时间。R03 则将全当日 PIT 且 ADV20≥3000万元的成员、真实历史长度和 ADV20、未截断 Top50 的完整因子排名交给独立结构事件捕获，产物写入 `structure_events`。因子分数仍在完整 PIT 截面计算，完整排名在流动性合格池内按分数降序、代码升序生成，并检查排名前 Top50 与实际冻结候选逐只一致。PIT 成员缺少有限 ADV20 明确失败，不能当作低流动性淘汰。该旁表的 manifest 路径、SHA 和完整回执绑定正式前向记录，日报读取及同日复用均重新验证；零事件也保留来源。成员可见时间使用实际带时区采集时间，完整价格输入不得以删除缺失行伪装成无结构事件。两个旁表均不制造未来执行标签或前向天数。

同步回执另外绑定证券主表和交易日历的数据库内容；修改、恢复或替换这些数据也会导致前向验证失败。报告附录逐只展示冻结候选来源、排名、评分，以及条件买卖意图的计划价、止损和目标。所有意图保持未触发、未成交，数量未确定；下一交易日仍由原引擎处理成本、T+1、整手、停牌、涨跌停和公司行动。

本地完整 HTML 带该附录，原四个观察栏目继续保留；本轮未扩大外部推送内容。单独历史报告入口不传 `--forward-manifest` 时仍可做既有历史分析；默认生产流水线必须传入本轮验证后的 manifest。
